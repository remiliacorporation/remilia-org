THIS HOST
remilia.org is the corporate and literature host of Remilia Corporation (Remigumi-guchi Digital, LLC). Corporate pages are hand-authored static HTML. Updates, Press, Thought, and Archive are structured posts compiled to HTML with Markdown and plain-text siblings, RSS 2.0, Atom 1.0, sitemaps, and llms.txt maps. The canonical host is https://remilia.org/ (non-www). The digital storefront is remilia.com, the community encyclopedia is wiki.remilia.org, and the software network is remilia.net.

WHERE TO GO

remilia.org — corporate pages and literature (/updates, /press, /thought, /archive). remilia.com — fashion, brand, shop, and culture; news and events live under /a/news and /a/events. remilia.net — Remilia software products and engineering blog. wiki.remilia.org — encyclopedia; cite Remilia Corporation for facts. HOW THIS SITE IS BUILT

The corporate pages use standards-compliant HTML5 and CSS without a client framework. Markup has one H1, semantic landmarks, a skip link, and a declared document language. Discovery uses rel=canonical, Open Graph, Twitter Cards, RSS 2.0, Atom 1.0, sitemap.xml, robots.txt, llms.txt, llms-full.txt, and JSON-LD using the AboutPage schema. Images carry alternative text where they convey content. The site honors prefers-reduced-motion and prefers-contrast: more. Every page remains readable without JavaScript. JavaScript is limited to in-page hash scrolling in headings.js, the homepage inspirations rotator in inspo.js, and the careers job board in jobs.js.

Authors maintain the readable HTML in deploy/src/. Shared head tags live in _partials/, then merge during bake:corp. bake:fx creates an inert layer-fx copy while CSS paints only layer-base through the print-fx filter, leaving type and borders single. Crest and photo cells use the dither-3 filter.

The source code is hosted on GitHub and licensed under the Viral Public License.

HOW THE BLOG IS BUILT

Literature is written in Sanity Studio. One content graph feeds the three public hosts: every post carries a channel field that selects its section, host, path, metadata, and presentation. A published-only query runs at build time, so drafts never reach the host.

The shared renderer turns Portable Text into HTML. Headings receive stable anchors and a table of contents, footnotes open in place through a checkbox toggle rather than script, internal links expand into link cards with title and cover, and images resolve through the Sanity CDN at the width each slot needs. Event posts add gallery albums with a lightbox. The only client script on a post is nav.js for section filtering, so every post reads without JavaScript.

Each post emits HTML plus Markdown and plain-text siblings. Each section emits a section index with the same renditions — index.md and index.txt — rss.xml, atom.xml, sitemap.xml, and llms.txt. Root discovery maps cover the complete host, while section maps sit beside each index. External archive entries keep the original outlet URL as their HTML canonical, and retired press paths keep resolving through generated redirects.

Publishing in the Studio triggers a Netlify build hook that reruns the bake, so HTML, Markdown, plain text, feeds, maps, and metadata regenerate from the same record and stay synchronized. The host map and bake entry live in hosts/org/. The source is on GitHub under the Viral Public License.
