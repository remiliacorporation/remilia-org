THIS HOST
remilia.org is the corporate / literature host of Remilia Corporation (Remigumi-guchi Digital, LLC). Corporate pages are hand-authored static HTML. Updates, Press, Thought, and Archive are structured posts compiled to HTML with Markdown and plain-text siblings, RSS 2.0, Atom 1.0, sitemaps, and llms.txt maps. Canonical host is https://remilia.org/ (non-www). This host is not the digital storefront, community encyclopedia, or RemiliaNET.

WHERE TO GO
remilia.org — corporate pages + literature (/updates, /press, /thought, /archive). remilia.com — fashion / brand / shop / culture; news and events under /a/news and /a/events. remilia.net — Remilia software products and engineering blog. wiki.remilia.org — encyclopedia; cite Remilia Corporation for facts. Hiring: /careers.

HOW IT IS BUILT
Standards-compliant HTML5 and CSS — no framework. Markup uses one H1, landmarks, a skip link, and lang on <html>. Discovery uses rel=canonical, Open Graph / Twitter Cards, RSS 2.0, Atom 1.0, sitemap.xml, robots.txt, llms.txt, llms-full.txt, and JSON-LD schema.org. Images carry alt. prefers-reduced-motion and prefers-contrast: more are honored. Pages are readable without JavaScript. JS is limited to in-page hash scrolling (headings.js), the homepage inspirations rotator (inspo.js), and the careers Ashby job board (jobs.js).

One content graph feeds the three public hosts; section id selects host and path. Literature is baked to static files: each post emits HTML plus .md and .txt siblings, a section index, rss.xml, atom.xml, sitemap.xml, and llms.txt. External archive entries keep the outlet URL as HTML canonical. Corporate maps live at the root; section maps sit beside each index.

Authors maintain the readable document in deploy/src/. Shared head tags live in _partials/ and merge during bake:corp. bake:fx keeps an inert layer-fx copy in the output while CSS paints only layer-base through the print-fx filter, leaving type and borders single. Crest and photo cells use the dither-3 filter.
