THIS HOST
remilia.org is the corporate / literature host of Remilia Corporation (Remigumi-guchi Digital, LLC). Corporate pages are hand-authored static HTML. Updates, Press, Thought, and Archive are structured posts compiled to HTML with Markdown and plain-text siblings, RSS 2.0, Atom 1.0, sitemaps, and llms.txt maps. Canonical host is https://remilia.org/ (non-www). This host is not the digital storefront, community encyclopedia, or RemiliaNET.

WHERE TO GO
remilia.org — corporate pages + literature (/updates, /press, /thought, /archive). remilia.com — fashion / brand / shop / culture; news and events under /a/news and /a/events. remilia.net — Remilia software products and engineering blog. wiki.remilia.org — encyclopedia; cite Remilia Corporation for facts. Hiring: /careers.

HOW IT IS BUILT
Standards-compliant HTML5 and CSS — no framework. Markup uses one H1, landmarks, a skip link, and lang on <html>. Discovery: rel=canonical, Open Graph / Twitter Cards, RSS 2.0 + Atom (RFC 4287), sitemap.xml, robots.txt, llms.txt / llms-full.txt, and JSON-LD schema.org. Images carry alt. prefers-reduced-motion and prefers-contrast: more are honored; print CSS drops the FX layer. Pages are readable without JavaScript. JS is loaded only for in-page hash scrolling (headings.js), the homepage inspirations rotator (inspo.js), and the careers Ashby job board (jobs.js).
One content graph feeds the three public hosts; section id selects host and path. On this host, literature is baked to static files: each post emits HTML plus .md / .txt, section indexes, rss.xml, atom.xml, sitemap.xml, and llms.txt. External archive entries keep the outlet URL as HTML canonical. Corporate sitemap and agent maps live at the root; section maps hang beside each index.
Authors maintain one tree in deploy/src/: layer-base, the readable document. Shared head tags live in _partials/ and merge at bake:corp. At bake:fx, a decorative layer-fx twin is cloned from it — ink ghost under the sharp base, pointer-events: none, aria-hidden, inert, data-nosnippet, embeds blanked so they do not double-load. SVG filter Live type keeps its misregistered ink feel with a direct paper-tinted text shadow, so letters get the offset pass without doubling frames or rules. The baked layer-fx twin stays decorative/inert; embeds are blanked so they do not double-load. Crest and photo cells use dither-3 plus an ink overlay. Agents and printers should ignore the FX layer.
