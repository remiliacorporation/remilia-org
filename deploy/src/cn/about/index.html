THIS HOST
remilia.org 是 Remilia Corporation（Remigumi-guchi Digital, LLC）的企业信息与文献站点。企业页面为 手工编写的静态 HTML。 更新、 新闻、 思想 和 归档 是结构化 文章，编译为 HTML，并配有 Markdown 与纯文本副本、 RSS 2.0、 Atom 1.0、 站点地图 和 llms.txt 映射。 规范站点地址为 https://remilia.org/ （不带 www）。数字店面为 remilia.com， 社区百科为 wiki.remilia.org，软件网络为 remilia.net。

WHERE TO GO

remilia.org ——企业页面与文献（/updates、/press、 /thought、 /archive）。 remilia.com ——时尚、品牌、商店与文化；新闻与活动位于 /a/news 和 /a/events。 remilia.net ——Remilia 软件产品与工程博客。 wiki.remilia.org ——百科全书；事实请引用 Remilia Corporation。招聘： /cn/careers。

HOW THIS SITE IS BUILT

企业页面使用符合标准的 HTML5 和 CSS，不使用 客户端框架。标记包含一个 H1、语义 地标、跳过链接，以及已声明的文档语言。 发现机制使用 rel=canonical、Open Graph、Twitter Cards、RSS 2.0、 Atom 1.0、 sitemap.xml、 robots.txt、llms.txt、 llms-full.txt，以及采用 AboutPage 模式的 JSON-LD。图像在传达内容时带有替代文本。 本站遵循 prefers-reduced-motion 和 prefers-contrast: more。每一页在没有 JavaScript 的情况下仍可阅读。JavaScript 仅限于 headings.js中的页内锚点滚动与语言选择设置、 inspo.js 中的首页灵感轮播，以及 jobs.js 中的招聘职位列表。

作者在 deploy/src/ 中维护可读的 HTML。共享的 head 标签位于 _partials/，随后在 bake:corp 期间合并。 bake:fx 创建非交互的 layer-fx 副本，而 CSS 仅通过 print-fx 滤镜绘制 layer-base，使文字与边框保持单层。纹章与照片单元格 使用 dither-3 滤镜。

源代码托管于 remiliacorporation/remilia-org，并依据 Viral Public License 授权。

HOW THE BLOG IS DESIGNED

博客并非一个碰巧容纳了文章的 Web 应用程序，而是一个最终生成文档的发布系统。 Sanity Studio 是编辑源，而非生产运行时。在构建 时，已发布的记录成为完整的 HTML 页面，在浏览器运行脚本之前即包含 其文本、导航、引用、元数据与链接。CSS 控制呈现与 原生界面状态；JavaScript 可以增强文档，但 从不拥有其路由或其内容。此处的静态意味着 已完成解析且可通过地址访问，而非静止不变。

一份 内容图 服务于三个主机。文章的 channel 选择其 栏目、源站、URL、元数据与视觉身份； 共享渲染器 在各处提供相同的文档契约： main、article、一个 h1、机器可读时间、稳定的标题 片段标识符、目录，以及规范链接与备用 链接。标签与作者归档、静态分页，以及 上一篇与下一篇链接，使归档可作为 超文本遍历，而非无限信息流。内部链接 仍是普通的 a 元素，但会展示 由目标记录的封面、标题与 描述构成的卡片。外部链接有可见标记，并声明 rel="external noopener"。没有私有路由器或 客户端缓存横亘在读者与 URL 之间。

交互始于浏览器原语。边注文本 始终存在于 HTML 中：在宽屏上 CSS 将其置于 引用旁的页边；在窄屏上，则通过复选框、:target 和悬停状态将其展开并覆盖在正文上方。链接卡片可通过悬停或聚焦触发。主题旋钮 是一组真实的输入控件，CSS 可通过 :has() 读取其状态。小型延迟脚本添加栏目 筛选、侧栏搜索、当前标题指示、复制 控件、链接卡片的触摸行为，以及活动图库 灯箱。移除它们后，文档仍然可读，链接仍然可用，分页仍可浏览，而且每一条注释仍会显示。

界面有意狭窄而有限。 索引 是一组 分页卡片；文章正文采用 560 像素宽的阅读栏，在 大屏幕上两侧分别是目录与引文栏以及 相邻文章栏。这些侧栏会折叠，而不是 挤压正文。颜色是单一的 --hue：纸张、 墨水、焦点状态、固定点阵与图像 抖动均在 oklch() 中计算，并在 黄色与青色本会失去 对比度之处予以补偿。Remilia.org 构建后呈现为浅色纸面上的红色，并带有 密点阵；remilia.com 为深色底上的红色且无点阵； remilia.net 为浅色底上的蓝色并带疏点阵。读者 的选择在首次绘制之前覆盖这些主机默认值。 照片经过处理，与页面融为一体——灰度、 有序半色调、像素墨水、当前色相——而非以未经处理的矩形悬置在页面之上。

互操作性是一种输出，而非一项承诺。每篇文章 均输出为 HTML、 Markdown 和 纯文本。 每个栏目发布可抓取的索引与目录、 RSS、 Atom、 站点地图 和 llms.txt。发现元数据与 JSON-LD 描述相同的记录； 别名成为重定向；外部归档条目保留 其原始的规范发布站点。烘焙过程为资源生成指纹， 在替换栏目之前拒绝不可读或意外为空的源数据， 并检查成品主机上的内部链接。发布会重新运行该 烘焙，因此，供读者阅读、供订阅源和爬虫获取以及供机器读取的视图会一并重新生成。 源码 依据 Viral Public License 发布。
