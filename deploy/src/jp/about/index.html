THIS HOST
remilia.org はRemilia Corporation（Remigumi-guchi Digital, LLC）のコーポレートおよび文学のホストです。コーポレートページは 手書きの静的HTMLです。 アップデート、 プレス、 思想、 アーカイブは、Markdownとプレーンテキストの兄弟ファイル、 RSS 2.0、 Atom 1.0、 サイトマップ、 llms.txtマップとともにHTMLへコンパイルされる構造化投稿です。 正規ホストは https://remilia.org/ （non-www）です。デジタルストアフロントは remilia.com、 コミュニティ百科事典は wiki.remilia.org、ソフトウェアネットワークは remilia.netです。

HOW THIS SITE IS BUILT

コーポレートページは、クライアントフレームワークなしで、標準に準拠した HTML5と CSSを使用しています。マークアップにはH1が1つ、セマンティックな ランドマーク、スキップリンク、宣言された文書言語があります。 ディスカバリーにはrel=canonical、Open Graph、Twitter Cards、RSS 2.0、 Atom 1.0、 sitemap.xml、 robots.txt、llms.txt、 llms-full.txt、および AboutPageスキーマを用いたJSON-LDを使用しています。画像は内容を伝える場合に代替テキストを伴います。 サイトはprefers-reduced-motionと prefers-contrast: moreを尊重します。すべてのページは JavaScriptなしでも読めます。JavaScriptは、 headings.jsにおけるページ内ハッシュスクロールと言語選択設定、 inspo.jsにおけるホームページのインスピレーションローテーター、 jobs.jsにおける採用のジョブボードに限られています。

著者は読みやすいHTMLを deploy/src/で維持しています。共有のheadタグは _partials/にあり、 bake:corpの際にマージされます。 bake:fx は不活性なlayer-fxコピーを作成し、CSSは print-fx フィルターを通してlayer-baseのみを描画し、書体とボーダーを一重のままにします。クレストと写真のセルは dither-3 フィルターを使用します。

ソースコードは remiliacorporation/remilia-org でホストされ、 Viral Public Licenseの下でライセンスされています。

HOW THE BLOG IS DESIGNED

ブログは、たまたま記事を含む ウェブアプリケーションではありません。文書へと解決される出版システムです。 Sanity Studio は編集ソースであり、本番ランタイムではありません。ビルド時に、公開済みレコードは、ブラウザがスクリプトを実行する前に、テキスト、ナビゲーション、引用、メタデータ、リンクを含む完全なHTMLページになります。CSSがプレゼンテーションとネイティブなインターフェース状態を制御します。JavaScriptは文書を向上させることはあっても、そのルートや内容を所有することはありません。ここでの静的とは、解決済みでアドレス可能であることであり、不活性であることではありません。

1つの コンテンツグラフ が3つのホストに提供されます。投稿のchannelがそのセクション、オリジン、URL、メタデータ、視覚的アイデンティティを選び、 共有レンダラー がどこでも同じ文書契約を提供します： main、article、1つの h1、機械可読な時刻、安定した見出し フラグメント、目次、正規リンクと代替 リンク。タグと著者のアーカイブ、静的ページネーション、前後のリンクにより、アーカイブは無限フィードではなくハイパーテキストとして辿れます。インターリンクは普通のa要素のままですが、対象レコードのカバー、タイトル、説明から構築されたカードを表示します。アウトリンクは視覚的にマークされ、 rel="external noopener"を宣言します。読者とURLの間にプライベートなルーターやクライアントキャッシュは介在しません。

インタラクションはブラウザのプリミティブから始まります。サイドノートのテキストは常にHTMLに存在します。広い画面ではCSSが参照の横のマージンに配置し、狭い画面ではチェックボックス、:target、ホバー状態がテキストの上に開きます。リンクカードはホバーとフォーカスで機能します。テーマダイヤルは、CSSが:has()で状態を読める実際の入力のグループです。小さな遅延スクリプトが、セクションのフィルタリング、レール検索、現在の見出しの表示、コピーコントロール、リンクカードのタッチ動作、イベントギャラリーのライトボックスを追加します。それらを取り除いても、文書は読め、リンクし、ページ送りし、すべての注を示します。

インターフェースは意図的に狭く、有限です。 インデックスはページネーションされたカードの集合です。記事は560ピクセルの読み幅で、大画面では目次と引用のレールと隣接投稿のレールが両脇にあります。それらのレールは散文を押しつぶすのではなく折りたたまれます。色は1つの--hueです。紙、インク、フォーカス状態、固定ドット格子、画像ディザーはoklch()で計算され、黄とシアンがコントラストを失うところでは補正されます。Remilia.orgは明るい紙の上に密な格子でベイクされた赤、remilia.comは格子なしの暗い紙の上の赤、remilia.netは明るい紙の上に疎な格子の青です。読者の選択は初回ペイント前にそれらのホスト既定を上書きします。写真はページに属するように作られます — グレースケール、秩序だったハーフトーン、ピクセルインク、現在の色相 — 手つかずの矩形としてその上に載るのではありません。

相互運用性は出力であり、約束ではありません。すべての投稿はHTML、 Markdown、 プレーンテキストとして出力されます。 すべてのセクションはクロール可能なインデックスとディレクトリ、 RSS、 Atom、 サイトマップ、 llms.txtを公開します。ディスカバリーメタデータとJSON-LDは同じレコードを記述します。エイリアスはリダイレクトになり、外部アーカイブのエントリは元の正規の掲載元を保持します。ベイクはアセットにフィンガープリントを付け、セクションを置き換える前に読めない、または予期せず空のソースデータを拒否し、完成したホスト全体の内部リンクを検査します。公開はそのベイクを再実行するため、人間、フィード、クローラー、機械可読なビューが一緒に再生成されます。 ソース は Viral Public Licenseの下で公開されています。
