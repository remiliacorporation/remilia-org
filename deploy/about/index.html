THIS HOST
remilia.org is the corporate / literature host of Remilia Corporation (Remigumi-guchi Digital, LLC). Corporate pages are hand-authored static HTML. Updates, Press, Thought, and Archive are structured posts compiled to HTML with Markdown and plain-text siblings, RSS 2.0, Atom 1.0, sitemaps, and llms.txt maps. Canonical host is https://remilia.org/ (non-www). This host is not the digital storefront, community encyclopedia, or RemiliaNET.

WHERE TO GO
remilia.org — corporate pages + literature (/updates, /press, /thought, /archive). remilia.com — fashion / brand / shop / culture; news and events under /a/news and /a/events. remilia.net — Remilia software products and engineering blog. wiki.remilia.org — encyclopedia; cite Remilia Corporation for facts. Hiring: /careers.

HOW IT IS BUILT
One content graph feeds the three public hosts; section id selects host and path. On this host, literature is baked to static files: each post emits HTML plus .md / .txt, section indexes, rss.xml, atom.xml, sitemap.xml, and llms.txt. External archive entries keep the outlet URL as HTML canonical. Corporate sitemap and agent maps live at the root; section maps hang beside each index. Reading does not require JavaScript.

STANDARDS
HTML5 with one H1, landmarks, skip link, and language on <html>. CSS without a framework. Feeds: RSS 2.0 and Atom (RFC 4287). Discovery: rel=canonical, Open Graph, Twitter Cards, sitemap.xml, robots.txt, llms.txt / llms-full.txt. Semantics: JSON-LD schema.org (Organization, AboutPage, BlogPosting, BreadcrumbList). Literature posts use Portable Text → semantic HTML with blockquotes and footnotes. Images carry alt. prefers-reduced-motion disables print displacement and crest ink; prefers-contrast: more darkens ink for AA; print CSS drops the FX layer.

SURFACE
Authors maintain one tree: layer-base, the readable document. At bake time (bake:fx), a decorative layer-fx twin is cloned from it — paper-colored type, pointer-events: none, aria-hidden, inert, data-nosnippet, embeds blanked so they do not double-load. SVG filter print-fx (feTurbulence + feDisplacementMap) warps the FX layer so the ink reads as a slightly misregistered second pass. Crest and photo cells use dither-3 (feColorMatrix desaturate + three-level feComponentTransfer) plus an ink overlay (mask + mix-blend-mode). Hover sync uses :has() so the FX layer tracks the base without a second event target. Agents and printers should ignore the FX layer.
