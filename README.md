# remilia-org

Public static site for [remilia.org](https://remilia.org/) plus the Sanity
Studio that edits the shared Remilia content graph (org / com / net).

| Host | Sections | Paths |
| --- | --- | --- |
| remilia.org | updates, press, thought, archive | `/updates`, `/press`, `/thought`, `/archive` |
| remilia.com | news, events | `/a/news`, `/a/events` |
| remilia.net | dev-updates, dev-blog | `/updates`, `/blog` |

Posts use schema field `channel` = section id (`dev-updates` so GROQ never
collides with org `updates`). Events are posts with gallery albums. Archive
entries can store a Firecrawl snapshot of an external outlet plus commentary.

```
deploy/          Netlify publish root (hand-authored corporate pages)
  updates|press|thought|archive/   generated by bake — gitignored
hosts/           bake + import scripts
packages/        shared renderer / seo helpers
schemaTypes/     Sanity schema
```

## Run

```bash
pnpm install
pnpm dev          # Studio — http://localhost:3333
pnpm bake         # bake:org (literature) then bake:fx (print FX twins)
pnpm validate
pnpm typecheck
```

- **Netlify** — `publish = deploy`, build = `pnpm bake`. Needs Sanity read
  credentials in the site env for `bake:org`.
- **Studio** — `pnpm run deploy:studio` → hosted Sanity Studio (not on remilia.org).
- Corporate HTML authors only `.layer-base`; `bake:fx` clones a decorative
  `.layer-fx` twin at build time (no client JS).

Publishing in Studio does not rebuild remilia.org by itself. Wire a Sanity
webhook → Netlify build hook (dataset `production`, filter `_type == "post"`),
or push / run `pnpm bake` locally.

## Going public

This repo is meant to be **public** so Netlify’s free tier can build from
GitHub. Before flipping visibility:

1. Confirm no secrets are tracked (`git ls-files | rg -i 'env|token|secret'`).
2. Beads issue data syncs on the same remote under `refs/dolt/data` and becomes
   fetchable when the repo is public (emails and internal task notes included).
   Keep that if you are fine with it, or point `sync.remote` at a private
   beads-only remote.
3. GitHub → Settings → General → Change repository visibility → Public.

Keep API tokens in Netlify / Sanity dashboards only.

## Layout

- `deploy/` — remilia.org corporate pages (about, careers, contact, home)
- `hosts/org/` — section chrome + org bake
- `hosts/bake-fx.ts` — print FX twin injection
- `schemaTypes/` — Sanity document/object types
- `structure.ts` — Org / Com / Net Studio desks

Import and migration scripts live under `hosts/`. See [docs/ops.md](docs/ops.md).
