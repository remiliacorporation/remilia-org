# remilia-org

Static site generator for [remilia.org](https://remilia.org/), Sanity studio blogs (org / com / net) and the shared Remilia content graph.

## Host map

| Host | Sections | Paths |
| --- | --- | --- |
| remilia.org | updates, press, thought, archive | `/updates`, `/press`, `/thought`, `/archive` |
| remilia.com | news, events | `/a/news`, `/a/events` |
| remilia.net | dev-updates, dev-blog | `/updates`, `/blog` |

## Layout

```
deploy/          Netlify publish root (assets, llms, sitemap; corporate HTML baked)
  src/           Hand-authored corporate sources (.layer-base only)
    _partials/   Shared head + SVG fragments (bake:corp)
  updates|press|thought|archive/   generated by bake:org — gitignored
hosts/org/       org section bake + chrome
hosts/bake-corp.ts  partial merge → deploy/
hosts/bake-fx.ts print FX twin from .layer-base
packages/        renderer, seo
schemaTypes/     Sanity schema
structure.ts     Org / Com / Net desks
```
